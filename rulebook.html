04 // MOVEMENT STANDARDS

NO REP IS NO REP.

경기 전 반드시 숙지하세요.

COMMON

DUMBBELL DROP

Dumbbell Drop 금지. 고의 또는 실수로 Drop 시 -1 Rep Penalty.

SYNC

DB SHOULDER TO OVERHEAD

귀보다 아래에서 시작. 두 선수 모두 Overhead Lockout 완료 시 1 Rep. Jerk / Push Press / Strict Press 가능.

BOX

DB BOX STEP OVER

양발이 모두 Box 위에 올라와야 하며 완전한 신전은 불필요. 양발이 반대편 바닥에 내려오면 1 Rep.

SYNC

DB HANG SNATCH

바닥에서 들어 올린 뒤 Hang에서 한 번의 연속 동작으로 Overhead. Shoulder에서 Press로 마무리하면 No Rep. 두 선수 Lockout 필요.

SYNC

DB THRUSTER

첫 Rep은 Squat Clean 가능. 고관절이 무릎 아래로 내려가는 Full Squat 후 두 선수 모두 Overhead Lockout.
